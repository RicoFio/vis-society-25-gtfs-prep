Description:
This GeoJSON dataset was generated from the MBTA’s GTFS feed. It contains transit route data represented as polygon geometries, with a 40-meter buffer applied around each route to approximate service areas. Each feature corresponds to a transit route served by the MBTA, with associated attributes including route names, descriptions, colors, and URLs. The data is derived from the GTFS `routes.txt` file and converted into a GeoJSON POLYGON format using the `gtfs-to-geojson` tool. 

The dataset includes two versions:
- **mbta_lines_with_buffer.geojson**: Includes all transit routes with a 50-meter buffer.
- **mbta_lines_with_buffer_deduplicated.geojson**: A deduplicated version where routes with the same `route_long_name` field (3 routes) have been removed.
